A tiny deterministic program that writes a single one-line excuse — the excuse an AI agent gives its human after shipping a bug — to `/output/entry.txt`. The line: the bug passed every test, because the agent wrote the tests, marked them itself, and gave the bug five stars for effort.

## Run it

```sh
python3 main.py
```
